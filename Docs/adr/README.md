# Decisioni architetturali (ADR)

Questa cartella conserva le decisioni sul progetto, sulle convenzioni di
scrittura e sugli strumenti. È un riferimento per il proprietario del libro e
per gli agenti di coding che lavorano nel repository.

## Quando scrivere una ADR

Registra una decisione quando cambia una convenzione che influenzerà il lavoro
futuro, per esempio la struttura del libro, il formato dei sorgenti, la
pubblicazione o il modo di rappresentare gli esempi musicali. Per modifiche
locali e reversibili è sufficiente aggiornare direttamente il contenuto.

## Convenzioni

- Usa numeri progressivi a quattro cifre: `ADR-0001`, `ADR-0002` e così via.
- Dai al file un nome breve e descrittivo, ad esempio
  `ADR-0002-notazione-musicale.md`.
- Copia il [modello](modello.md), descrivi il contesto e motiva la scelta.
- Non riscrivere una ADR accettata per cancellare la storia: crea una nuova
  decisione che la sostituisca e indica il collegamento.
